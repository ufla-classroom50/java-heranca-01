# 📚 Exercício de Programação Orientada a Objetos em Java — Classroom50

Este repositório é um template de atividade da disciplina, integrado ao sistema de avaliação automática com Inteligência Artificial (**Classroom50 Autograder**).

---

## 🚀 Como Submeter sua Solução (Para Alunos)

1. Implemente o seu código Java dentro do diretório `src/`.
2. Para disparar a avaliação automática via IA:
   * **Abra um Pull Request (PR)** da sua branch apontando para a branch `main`.
3. Aguarde alguns segundos enquanto o pipeline executa a verificação.
4. O bot irá comentar diretamente no seu Pull Request com:
   * **Resultado** (Certo, Parcialmente Certo ou Errado).
   * **Justificativa** e análise pedagógica do seu código.
   * **Dicas de Correção** e sugestões de refatoração.
